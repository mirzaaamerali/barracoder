Mission 0

Meet your robot

Before you build or code anything, get to know your two tools: the SPIKE Prime hub and the Pybricks language that controls it.

MISSION 00

What is Pybricks?

Read5 min

Pybricks is a way to write real Python code that controls LEGO® robots. Instead of snapping together colored code blocks, you'll type actual commands — the same kind professional programmers use.

Your robot's brain is the SPIKE® Prime Hub: a small computer with buttons, a light-up grid, a speaker, and ports where motors and sensors plug in.

  • Get a LEGO® SPIKE® Prime set (or SPIKE Essential, Technic, or MINDSTORMS — Pybricks works with several hubs).
  • Open code.pybricks.com in a browser, or install the Pybricks app on a phone or tablet.
  • Connect the hub over USB cable or Bluetooth — a green light means you're linked up.
Try it

Turn on your hub by pressing the center button. Watch the light-up grid say hello — that grid is called the Light Matrix, and you'll control it yourself in Mission 4.

Coach tip

Pair students up: one drives the mouse/keyboard, one reads instructions aloud. Swap roles every mission.

Mission 1

Build the base

Every mission below assumes the StarterBot: two motors, two wheels, a ball caster, plus a color sensor and an ultrasonic distance sensor.

MISSION 01

Build the StarterBot

Build30–45 min

Follow the official build instructions at pybricks.com/learn/building-a-robot/spike-prime. You're building in three stages:

  • Base: the hub sits on top, two motors drive the left and right wheels, and a ball caster at the back keeps it balanced.
  • Eyes: an Ultrasonic Sensor bolts on the front — it "sees" distance, like a bat using echoes.
  • Feelers: a Color Sensor for spotting lines on the floor, plus two bumpers that press the hub's left and right buttons when the robot bumps into something.

Note which port each motor and sensor plugs into (A, B, C, D, E, or F) — you'll need those letters in Mission 2.

Try it

Spin each wheel by hand. If the hub is on, you should feel a tiny bit of resistance — that's the motor sensing the movement.

Mission 2

Say hello

Your first program doesn't need to move a single wheel. It just needs to prove the hub is listening to you.

MISSION 02

Your first program

Code10 min

Every Pybricks program starts by importing the parts you need, then waking up the hub. Type this into a new project at code.pybricks.com:

from pybricks.hubs import PrimeHub
from pybricks.parameters import Color

hub = PrimeHub()
hub.light.on(Color.GREEN)
print("Hello, robot!")

Press the green Play button. The hub's status light should turn green, and "Hello, robot!" will appear in the console at the bottom of the screen.

Try it

Change Color.GREEN to Color.MAGENTA and the message to your own name. Run it again.

Coach tip

Point out capitalization and indentation now — Python cares about both, and it's easier to build the habit on a four-line program.

Mission 3

Get moving

Two motors become one steerable robot with a single command: DriveBase.

MISSION 03

Drive straight and turn

Code15 min

Tell Pybricks which ports your motors are plugged into, wrap them in a DriveBase, and give distances in millimeters and angles in degrees:

from pybricks.pupdevices import Motor
from pybricks.parameters import Port
from pybricks.robotics import DriveBase

left_motor = Motor(Port.A)
right_motor = Motor(Port.B)
drive_base = DriveBase(left_motor, right_motor,
                        wheel_diameter=56, axle_track=114)

drive_base.straight(250)   # drive forward 250 mm
drive_base.turn(90)        # spin right 90 degrees
drive_base.straight(-250)  # back up 250 mm

If your robot drives backward when you say straight(), one motor is mirrored — fix it by wrapping that motor's port with Direction.COUNTERCLOCKWISE.

Try it

Chain four straight(250) and turn(90) pairs in a row. Does your robot end up back where it started — a perfect square?

Mission 4

Sound & light

Give your robot a voice and a face using the built-in speaker and the 5×5 Light Matrix.

MISSION 04

Beep and glow

Code10 min
from pybricks.hubs import PrimeHub
from pybricks.parameters import Color

hub = PrimeHub()

hub.speaker.beep(500, 200)   # 500 Hz tone for 200 ms
hub.light.on(Color.ORANGE)      # status light turns orange
hub.display.text("HI")         # scroll "HI" across the matrix

The first number in beep() is the pitch in Hertz — higher numbers sound higher. The second is how long the beep lasts, in milliseconds.

Try it

Write three beeps in a row, each a little higher-pitched than the last — a tiny rising alarm sound.

Mission 5

Wait & repeat

Pausing and looping are how a handful of commands turn into a whole routine.

MISSION 05

Patrol in a loop

Code15 min

wait() pauses for a number of milliseconds. A while True: loop repeats its indented block forever, until you stop the program:

from pybricks.tools import wait

while True:
    drive_base.straight(200)
    drive_base.turn(90)
    wait(300)  # pause a third of a second between moves

Want a fixed number of laps instead of forever? Swap the loop for for lap in range(4): so it counts to four and stops.

Try it

Replace while True with for lap in range(4) and drive a perfect square, then stop automatically.

Coach tip

This is a good moment to talk about infinite loops on purpose vs. by accident — ask students to predict what happens if they forget the wait().

Mission 6

Sense the world

Sensors turn a robot that follows a script into one that reacts — the last skill before free-form building.

MISSION 06

Stop before you crash

Code20 min

Read the Ultrasonic Sensor's distance() in millimeters, and the Color Sensor's color() as a named color. Combine a sensor reading with an if statement to make a decision:

from pybricks.pupdevices import UltrasonicSensor
from pybricks.parameters import Port

eyes = UltrasonicSensor(Port.D)

while True:
    if eyes.distance() < 100:      # closer than 100 mm?
        drive_base.stop()
        hub.speaker.beep(300, 300)
    else:
        drive_base.drive(150, 0)   # cruise forward at 150 mm/s

Same idea works for the Color Sensor — swap in colors = ColorSensor(Port.C) and check if colors.color() == Color.RED: to make your robot react to a colored card or a line on the floor.

Try it

Hold your hand in front of the sensor and pull it away. Watch the robot start and stop — then try changing 100 to a bigger or smaller number.
