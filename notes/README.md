# Shared notes & ideas

Space for coaches, teachers, and volunteers to share write-ups: meeting recaps,
activity ideas, scrimmage observations, things to try next.

**How to add a note:** create a markdown file here named
`YYYY-MM-DD-short-topic.md` (e.g. `2026-09-15-team-model-ideas.md`) — commit it
directly on GitHub with the pencil/"Add file" button, no local setup needed.
It renders right on GitHub for everyone with the link.

**Ideas and discussion** that don't need a document work great as
[GitHub Issues](https://github.com/mirzaaamerali/barracoder/issues) — one idea
per issue, comment to discuss.

Please keep student and family personal information out of everything here —
this repo is public.
