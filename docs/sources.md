# Where these materials come from

Everything under [season/](../season/) is official FIRST® LEGO® League
**Challenge** material for the BioGlow season (Founders Edition, grades 4–8,
SPIKE Prime), downloaded from the FIRST season-resources pages. It is © FIRST
and the LEGO Group and is redistributed here solely for the use of the
Barracoder team (White Lake Robotics).

If you are from another team: please download your own copies from the
official source so you always have the current revision:

- FIRST LEGO League season resources: https://www.firstlegoleague.org/season
- Class packs / Canopy certificates: https://www.firstinspires.org/

## Inventory

- Team Meeting Guide, Robot Game Rulebook, Engineering Notebook, season overview
- Session slide decks: intro + Sessions 1–12
- Mission-model build instructions Books 1–13, prepack, EOP
- Field setup reference guide + wireframe grid
- Guided mission SPIKE Prime program (`.llsp3`)
- Multimedia resources; certificate templates
